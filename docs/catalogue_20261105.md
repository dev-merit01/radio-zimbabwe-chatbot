# Verified catalogue batch — 5 November 2026

192 distinct recordings, sourced from distributor catalogue records and artist releases. Repeated feature variants are consolidated. This batch contains international and earlier releases as well as Zimbabwean 2026 releases; it does not assert annual-chart eligibility.

## Import behaviour

The web startup runs `python manage.py import_verified_catalogue --all-stations` after migrations. Each of the six configured stations is processed under its station lock in a transaction. The `verified_seed` audit records a batch ID, file digest, created IDs, sources and preserved decisions. Repeat execution is a no-op. Existing pending/rejected/verified entries are retained; version labels are not stripped. No vote, tally or mapping tables are changed.

Aliases in the manifest support duplicate detection during import only. They are not new vote mappings. Runtime AI matching remains responsible for interpreting incoming votes. The earlier 203-song research file is not included in this batch.
